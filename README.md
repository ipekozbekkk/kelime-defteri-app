# Akıllı Kelime Defterim (AI Destekli Web Geliştirme)

Bu proje, Software Persona Mesleki Gelişim Programı kapsamında yapay zeka asistanı desteğiyle geliştirilmiş modern bir kelime defteri web uygulamasıdır.

## Kullanılan Teknolojiler
- **HTML5 & Modern JavaScript (ES6+)**
- **Tailwind CSS** (Modern arayüz ve responsive tasarım için)
- **LocalStorage API** (Verilerin tarayıcıda kalıcı olarak saklanması için)

## Yapay Zekanın Kullanıldığı Aşamalar
- **Planlama:** Veri modelinin (kelime, anlam, kategori, örnek cümle) ve arayüz hiyerarşisinin belirlenmesi.
- **Kod Üretimi:** LocalStorage CRUD işlemlerinin ve Tailwind bileşenlerinin hızlıca yapılandırılması.
- **Dokümantasyon:** Proje açıklaması ve README taslağının oluşturulması.

## Kurulum ve Çalıştırma
Projeyi çalıştırmak için herhangi bir kurulum gerekmez. `index.html` dosyasını doğrudan bir tarayıcıda açabilir veya canlı bağlantıyı ziyaret edebilirsiniz.v
